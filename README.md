# C: Meu Caderno de Estudos

Bem-vindo ao meu repositório de estudos de C.

Aqui eu reúno **tudo o que aprendo sobre C**: da sintaxe básica até conceitos avançados de programação, gerenciamento de memória e projetos práticos. A ideia é que este repositório cresça junto comigo, funcionando como caderno de anotações, banco de exercícios e portfólio.

> **Em construção constante.** Toda vez que eu estudar algo novo, vai aparecer por aqui.

---

## Objetivo

Construir uma base sólida em C e documentar a jornada, cobrindo:

- Fundamentos da linguagem
- Estruturas de dados
- Ponteiros e gerenciamento de memória
- Programação modular
- Bibliotecas e ferramentas
- Projetos práticos
- Anotações e exercícios

---

## Estrutura do repositório

```text
C/
├── fundamentos/       # Sintaxe, variáveis e operadores
│   ├── hello_world.c
│   └── variaveis.c
├── condicionais/      # Estruturas condicionais
├── loops/             # Estruturas de repetição
├── funcoes/           # Funções e modularização
├── ponteiros/         # Ponteiros e memória
├── estruturas/        # Arrays, strings e structs
└── projetos/          # Projetos práticos
```

Cada pasta representa **um tema**, com exemplos e exercícios em arquivos `.c`.

## Como usar este repositório

Clone o projeto:

```bash
git clone https://github.com/samuelANROD/C.git
cd C
```

Os exemplos podem ser compilados com GCC:

```bash
gcc fundamentos/hello_world.c -o hello_world
```

Execute:

```bash
./hello_world
```
